# Journey image prompts

Four images for `JourneyTimeline.tsx`, one per step, designed as a set: same character, same style, same palette.

- **Target size:** 1600 × 2000 px (4:5, portrait)
- **Export:** WebP, quality ~86, saved as `public/journey/step-1.webp` … `public/journey/step-4.webp`
- **Current files:** generated from these prompts (step 1 first, then used as the character reference for steps 2–4), cropped to 4:5 and upscaled from the generator's 864 × 1152 output. Regenerate at a higher native resolution for the sharpest result.
- Below 1024px the same files are shown cropped to 4:3, so keep the subject in the central band of the frame.

## Shared style (already included in every prompt)

- Clean, modern 3D illustration, soft studio lighting, smooth matte materials, gentle depth of field, calm premium feel.
- Palette: brand blue `#1E4ED8` as the main accent, soft neutrals (off-white, light grey, slate), one subtle warm accent.
- Main character in every image: a young Tunisian man in his mid-20s, short dark hair, simple navy hoodie.
- Subtle, respectful Tunisian setting cues (Mediterranean apartment, white-and-blue architecture through a window). No flags or landmark clichés.
